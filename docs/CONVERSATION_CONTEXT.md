# Conversation Context & Memory

ไฟล์นี้เก็บข้อมูลสำคัญจากการสนทนาระหว่างผู้พัฒนาและ AI coding assistant เพื่อให้สามารถอ้างอิงได้ในอนาคต

---

## ข้อมูลสำคัญที่ควรจำ

### สไตล์การทำงาน
- ผู้พัฒนาใช้ภาษาไทยในการสื่อสาร
- ต้องการคำอธิบายเป็นภาษาไทย

### โครงสร้างโปรเจกต์
- โปรเจกต์: LunaAI v10
- Stack: Node.js + Express + VTube Studio + Solana + RPS web pages
- มีระบบ protected files ที่ห้ามแก้ไข (ดู `.cursorrules` หรือ repo rules)

### วันที่สร้างไฟล์นี้
- 2025-01-21: สร้างไฟล์นี้เพื่อบันทึกการสนทนา

---
