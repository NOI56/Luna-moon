#### 5.1 Referral System

**รางวัล:**
- **100 Luna** - เมื่อเพื่อนลงทะเบียน (signup)
- **200 Luna** - เมื่อเพื่อนเล่นเกมแรก (first game)

5. แชร์ให้เพื่อน

**API Endpoints:**
- `POST /luna/referral/register` - ลงทะเบียน referral
- `GET /luna/referral/stats?wallet=...` - ดูสถิติ
- `GET /luna/referral/link?wallet=...` - ดู referral link
