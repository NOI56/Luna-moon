🌙 Luna Token

Luna Token is a utility token for the Luna AI Ecosystem, used to access various features and reduce fees

💎 Key Features:
  • Utility Token for accessing various features
  • Token Burning: 3% from every deposit (True Burn)
  • Dynamic Pricing: Adjusts based on real-time price
  • Grandfathering: Maintains original privileges even if price changes

🔥 Token Burning System

True Burn mechanism on Solana Blockchain:

  • 3% of deposit amount is sent to Incinerator Address
  • Incinerator Address has no Private Key
  • Tokens are permanently burned
  • Verifiable on Solscan
  • Helps reduce supply and increase token value

📊 Dynamic Pricing System

Minimum Requirements adjust based on Luna's real-time price:

  • Based on Market Cap, Volume, Liquidity
  • Each feature has different Base USD value
  • Grandfathering: Depositors maintain original privileges
  • Auto-updates based on DexScreener data

❓ Frequently Asked Questions

Q: How do I get started with Luna AI?
A: First, install Phantom Wallet and connect it. Then check the Dynamic Minimum Requirements for the feature you want to use. If you need to deposit, go to the Deposit Luna page to get started.
Q: What is Dynamic Pricing?
A: Dynamic Pricing adjusts minimum requirements based on real-time Luna token price, market cap, volume, and liquidity. This ensures fair access regardless of market conditions.
Q: What is Grandfathering?
A: Grandfathering means if you deposit when the minimum is 10 USD, you keep that requirement even if the price changes and the new minimum becomes 15 USD. Your privileges are locked at deposit time.
Q: Is token burning permanent?
A: Yes! Tokens are sent to the Solana Incinerator Address which has no private key. This means they are permanently removed from circulation and cannot be recovered. You can verify burns on Solscan.
Q: Can I withdraw my deposit anytime?
A: Yes, you can withdraw your deposit at any time from the Deposit Luna page. However, withdrawing will remove your fee reduction and feature access privileges until you deposit again.
Q: What happens if I don't meet the minimum requirement after price changes?
A: If you already deposited, Grandfathering protects you. If you haven't deposited yet, you'll need to meet the current Dynamic Minimum Requirement to access features.
Q: How does the competition system work?
A: Weekly competitions track your performance in Rock Paper Scissors games. Top 5 players receive rewards automatically distributed at the end of each week.
Q: Can I use multiple wallets?
A: Each wallet is tracked separately. The system includes anti-abuse measures to prevent unfair advantages from multiple wallets.
